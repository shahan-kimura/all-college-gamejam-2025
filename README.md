# ALL COLLEGE GAME JAM 2025 SHOWCASE (全国14校舎・全40作品)

全国14校舎のゲームカレッジによる「オールカレッジゲームJAM2025」の成果物を網羅したインタラクティブ・プレビューサイトです。

## 特徴
1. **GFF2026デザイン準拠**: 全画面ループ動画背景、FUI/HUDサイバーパンク調Neo-Brutalistデザイン。走査線エフェクトは背景背面(`z-index: -1`)に配置し、モーダルや資料、UIの視認性を邪魔しません。
2. **校舎別展開サイドバー (Drawer Menu)**:
   - 「☰ 校舎別作品リスト (40作品)」ボタンをクリックすると、右側からサイドバーがスライドイン。
   - 全国14校舎ごとに整理された全40作品リストからワンクリックで各作品ページへ遷移可能。
3. **校舎クイックフィルタ**:
   - メイン画面上部の校舎タグフィルターで、目的の校舎の作品だけを瞬時に絞り込み表示。
4. **ローカル素材を使った展示プレビュー**:
   - `LAUNCH_SHOWCASE.bat` または `index.html` を開くと、サイト内の動画・サムネイル・資料を表示できます。
   - PDFビューアが使えない環境向けに、スライド画像へ切り替えられます。ゲーム配布リンクを開くにはインターネット接続が必要です。
5. **個人情報保護**:
   - 企画書PDF・ページ画像・サムネイル・動画内で確認された個人名は不可逆マスキングし、PDFの個人情報メタデータを削除しています。
   - 学生IDとメールアドレスは公開対象から確認されませんでした。
6. **ゲーム配布リンク**:
   - 40作品のうち35作品は、ゲーム本体の配布物または実行用フォルダーをGoogle Driveで開けます。
   - 次の5作品は、確認できるゲーム本体の配布物がないため、サイト上で未配布と表示します: BOMBERJUMPER、BlowAway、ハ花ナ火び (ハナビ)、Bomb！Bomb！DASH！、人気爆発！！地雷ちゃん。

## オンライン公開
- このフォルダーをリポジトリのルートとして管理し、GitHub Actions がルートの展示サイトを GitHub Pages に公開します。
- ゲーム配布物はこのサイトに含めず、Google Drive のリンク先で開きます。リンクの利用にはインターネット接続が必要で、Drive 側の公開状態に依存します。
- 元の配布 ZIP と個人情報監査の確認資料は、このサイトリポジトリの外に保管しています。
- 更新時は、このリポジトリのルートにある展示ページ、資料、画像、動画を編集して `main` に反映します。
